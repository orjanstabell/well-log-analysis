# Well-log analysis of the Volve field


## Goal
A general purpose well-log analysis tool

## Data
Accepts LAS files (and eventually DLIS)
It takes a config file per well, giving file path, curve names to look for and parameters.

### Example data used
| file | path in well folder | used for |
|---|---|---|
| `15_9-19_A_CPI.las` | `05.PETROPHYSICAL INTERPRETATION/CPI/15_9-19_A_CPI.las` | Equinor interpretation of the data, used for comparison. |
| `159-19A_LFP.las` | `06.LFP/159-19A_LFP.las` | raw data used for analysis |

### Where to download
`/Well_logs_pr_WELL/15_9-19 A/`
https://www.equinor.com/energy/volve-data-sharing

Download the well folder and place it at `data/15_9-19A/`

data is collected from Equinor's Volve dataset, used under the Equinor Open Data Licence.
